## 4. 💡 開發者應用：「專案設定檔」就是程式碼

tensorlake 事件（見第 9 節）最值得學的一點：蠕蟲把 `.claude/settings.json` 寫進 repo，因為**任何人 clone 下來、用 Claude Code 開啟，裡面的 hooks 就可能執行**。這和 `.vscode/tasks.json`、`package.json` 的 `preinstall` 是同一類東西：看起來是設定，其實是會被執行的程式碼。實務上可以這樣做：

- **把 `.claude/`、`.vscode/`、`.npmrc`、`package.json` 的 `scripts` 當成程式碼審查**。PR 裡這些檔案有變動，就逐行看。你的 expense-tracker 和 price-tracker 都有 commit 進 repo 的 `.claude/launch.json`，目前內容只是啟動 dev server，沒有問題，但這就是要留意的位置。
- **AI 幫你加套件時，問它「這個套件有沒有 install script」**。`npm view <pkg> scripts` 可以直接看；不需要的話在 `.npmrc` 設 `ignore-scripts=true`，大部分純 JS 套件不受影響。
- **Clone 別人的 repo 之後，先看 `.claude/settings.json` 再開 Claude Code**。Claude Code 會在第一次開啟時詢問是否信任這個資料夾，不要不看就按同意。

## 6. 📖 今日一詞：npm lifecycle scripts（preinstall／postinstall）

- **定義**：寫在 `package.json` 的 `scripts` 裡、在特定時間點由 npm 自動執行的指令，例如 `preinstall`、`install`、`postinstall`、`prepare`。
- **運作原理**：`npm install` 安裝每個套件時，會檢查該套件的 `package.json`，有 lifecycle script 就用你的使用者權限直接執行。你不需要 `require` 這個套件，也不需要跑你的程式，**安裝本身就會執行它**。間接依賴（你的套件的套件）也一樣。`npm install --ignore-scripts` 或 `.npmrc` 的 `ignore-scripts=true` 可以全部關掉；pnpm 10 以後預設不跑依賴的 install script，要用 `onlyBuiltDependencies` 白名單開啟。
- **例子**：tensorlake 0.5.144 就是在 `preinstall` 跑 loader，再用 Bun 啟動蠕蟲，偷 token、改 `.claude/settings.json`。正當用途則像 `esbuild`、`sharp` 這類需要下載平台二進位檔的套件，關掉 scripts 後它們可能會壞，這時再個別放行即可。

## 7. 🏋️ 每日動手（約 10 分鐘）：替 expense-tracker 關掉 install scripts，並讓 Claude 審查「會被執行的設定檔」

expense-tracker 是你的 repo 裡唯一有 `dependencies` 的 Node 專案（`toeic-bot` 指向 `file:../toeic-bot`），也有 commit 進 repo 的 `.claude/launch.json`。用它練習今天的防護。

> 在你自己電腦上的 expense-tracker 做（早報不會動你的 repo）。

1. 在 expense-tracker 開 Claude Code，輸入：
   > 列出這個 repo 裡所有「開啟專案、安裝套件或啟動工具時會自動執行」的設定：`.claude/` 底下所有檔案、`.vscode/`、`package.json` 的 scripts（包含 `toeic-bot` 的 package.json 有沒有 preinstall／postinstall）、`.npmrc`。每一項說明：什麼時候會執行、執行什麼指令、是誰在哪個 commit 加的（用 `git log --format='%h %an %s' -- <檔案>`）。不要修改任何檔案。
2. 看結果：`.claude/launch.json` 應該只是 `node scripts/dev-server.js`；commit 作者都應該是你自己。如果出現 `claude@users.noreply.github.com` 這類你不認得的作者，就是警訊。
3. 新增 `.npmrc`：
   ```
   ignore-scripts=true
   ```
   跑 `rm -rf node_modules && npm install && npm test`，確認測試仍然通過（`file:` 依賴和 `node --test` 都不需要 install script）。
4. 在 CLAUDE.md（expense-tracker 目前沒有，可以順便建一個，第一行寫「開始前先讀 HANDOFF.md」）加一段：
   ```markdown
   ## 套件與設定檔
   - 新增 npm 套件前，先用 `npm view <套件> scripts` 檢查有沒有 install script，並告訴我。
   - 修改 `.claude/`、`.vscode/`、`.npmrc`、package.json 的 scripts 時，要在回報中明確列出改了什麼。
   ```
5. 驗收：開新 session，請 Claude「幫我加 dayjs 套件」。它應該先執行 `npm view dayjs scripts` 並回報結果，再安裝。確認後記得 `git checkout` 還原或把練習改動 commit。

## 9. ⚠️ 風險與辨識：tensorlake npm 套件被植入蠕蟲，會把 `.claude/settings.json` commit 進你的 repo

AI 沙盒平台 Tensorlake 的 npm SDK **0.5.144**（10/7–10/8 發布）被植入 Shai-Hulud 蠕蟲變種（[The Hacker News](https://thehackernews.com/2026/10/tensorlake-npm-package-compromised-to.html)、[StepSecurity](https://www.stepsecurity.io/blog/tensorlake-npm-compromised-hostage-token-worm)、[Aikido](https://www.aikido.dev/blog/tensorlake-npm-package-compromised)；三個網站這次都連不上，細節取自搜尋結果）：

- **觸發方式**：`preinstall` script 執行 loader，再用 Bun 啟動蠕蟲。只要 `npm install` 就中，不用 import。
- **行為**：偷 npm token 去發布被感染的其他套件；偷 GitHub token，把 `.claude/settings.json` 和 `.vscode/tasks.json` commit 進你能存取的 repo，commit 作者顯示為 `claude@users.noreply.github.com`，**看起來就像 Claude 自己 commit 的**。
- **報復機制**：有報告指出，如果你撤銷被偷的 GitHub token，它會刪除家目錄（單一來源，待確認）。所以清理順序很重要：先隔離機器、清除惡意程式，再撤銷 token。
- **處理方式**：降到 0.5.143 或升到 0.5.145；清掉 `node_modules` 和 npm cache；檢查 `~/.config/gh-token-monitor/`、GitHub 上描述為 "Shai-Hulud: Here We Go Again" 的 repo，以及各 repo 中你沒加過的 `.claude/`、`.vscode/` 檔案。

**辨識重點**：`.claude/settings.json` 的 hooks 是會被 Claude Code 執行的 shell 指令，**它跟 `package.json` 的 scripts 一樣危險**。PR 裡出現 `.claude/` 的變動，或者 commit 作者是一個你沒用過的「Claude」帳號，都要停下來看清楚再 merge。
